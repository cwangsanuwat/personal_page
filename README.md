# Chatarin Wangsanuwat — personal website

A small, static personal academic site designed for GitHub Pages. It uses plain HTML and CSS, so text can be edited directly in the `.html` files without a build step.

## Pages

- `index.html` — biography and education
- `publications.html` — selected publications
- `teaching.html` — program leadership and teaching
- `talks.html` — selected talks, outreach, and training
- `projects.html` — KidGeneVAI
- `contact.html` — LinkedIn and professional links (no email address is published)

## Publish with GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root (including `assets/`).
3. In the repository, open **Settings → Pages** and select the `main` branch and `/ (root)` as the publishing source.
4. Wait for GitHub Pages to publish the site at `https://<your-github-username>.github.io/`.

No custom domain, paid hosting, or build process is required. The repository must be public for GitHub Pages on GitHub Free.

## Editing

Open the relevant HTML file and edit its text. Keep the existing tags and punctuation around the text. Replace the portrait at `assets/chatarin-wangsanuwat.jpg` if you want to use a different photo. The site palette takes its cue from the Siriraj Genomics logo: green as the primary accent, supported by blue and white.
